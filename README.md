# Emphile Cleaning Solutions Ltd — Website

Static one-page website for Emphile Cleaning Solutions Ltd, a Nigeria-based professional and eco-friendly cleaning and facility support company.

## Placeholders

Several fields are placeholders (highlighted with a dashed underline on the page) and should be filled in before the site is considered final:

- RC / company registration number
- Operations office address
- Phone number
- Email address
- City/State served
- Website domain
- Social media handles

## Hosting

This site is a single static `index.html` file with no build step — it can be served as-is via GitHub Pages, Netlify, or any static host.
